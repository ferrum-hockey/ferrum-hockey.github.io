# ХК «Феррум» — GitHub Pages

Сайт: https://southfamily-hockey.github.io/ferrum-hockey/

Отдельная копия сайта. Cloudflare Pages, Worker бота, D1 и матчевый Cron не меняются.
GitHub Actions только читает их публичные данные, без токенов Telegram/Cloudflare.

## Обновление

Проверки идут в минуты 7, 17, 27, 37, 47, 57 каждого часа. Если данные изменились,
создается статическая сборка. GitHub может задерживать расписание; точного срока нет.
Actions → Publish Ferrum → Run workflow запускает обновление вручную.
Бот и его кнопки прежние. Матчи берутся из существующего ежедневного снимка РХЛ.
AI не используется. Посетитель получает все страницы, данные и фото с GitHub Pages.

## Фото и доступ

Черновики сборщику недоступны. Опубликованные фото скачиваются только в dist/media
во время сборки, а не коммитятся в репозиторий. В новой сборке снятые с публикации
фото удаляются. Уже сохраненные чужие копии и кеши отозвать нельзя. Артефакты — 1 день.
Статические фото тренеров/состава в site уже публично размещены на сайте клуба.
Секреты бота, приватная база и Telegram ID редакторов сюда не переносятся.

## Разработка

Node.js 22+, без дополнительных пакетов: npm test; npm run build.
config.json задает публичные источники и адрес Pages. Некорректные/неполные данные
останавливают сборку: предыдущая версия сайта остается. Неизменившийся снимок не
развертывается повторно. Предел сборки 950 МБ; рост архива нужно контролировать.
Шрифты Roboto Condensed поставляются с OFL в site/assets/fonts.

После успешного развертывания служебный коммит обновляет .sync-state.json (хеш и дата,
без фото). Ежедневный снимок РХЛ обеспечивает регулярные обновления и активность.
Следует контролировать Actions: GitHub может задерживать расписания и отключает
их после 60 дней без активности репозитория. Стандартные runners публичных репозиториев
используются без платных runners/сервисов.

Тесты проверяют маршруты, данные, пагинацию, копирование только опубликованных фото,
снятие публикации, отказ при сбое источника и пропуск неизменившихся снимков.
